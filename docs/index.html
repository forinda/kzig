kzig.

KickJS for Zig: modules, controllers, services, middleware, context contributors and adapters, with KickJS's boot order and request pipeline, built on comptime. A missing service or an unknown handler fails zig build, not the first request.

Pre-alpha. Requires Zig 0.17.0. APIs will change.

A controller

pub const HelloController = struct {
    hello: *HelloService, // injected at compile time

    pub const routes = .{
        .{ .method = .GET, .path = "/", .handler = "index" },
    };

    pub fn index(self: *HelloController, ctx: *kzig.Ctx) !Greeting {
        _ = ctx;
        return self.hello.greet("World");
    }
};
